# ogamed (Live-Stand)

Go-Teil von TBot-5a (Fork von alaingilbert/ogame). Nur der produktiv genutzte Code:
`ogame.go`, `pkg/` und `cmd/ogamed-tbot/`.

Bauen: `cd ogamed && go build -o ogamed ./cmd/ogamed-tbot`
Oder alles zusammen: `./build-all.sh` im Repo-Root.

Das Binary muss als `ogamed` im Arbeitsverzeichnis von TBot liegen (/home/tbot/tbot).

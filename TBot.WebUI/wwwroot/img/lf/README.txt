Lebensform-Bilder fuer die Config-Seite "Brain > LifeformAutoResearch".
Die Seite zeigt sie mit 26x26 Pixel. Pro Tech wird in dieser Reihenfolge gesucht:

  1. Wiki-Name (Dateien aus dem OGame-Wiki koennen unveraendert hineinkopiert werden):
       Humans-research-1-200px.jpg ... Humans-research-18-200px.jpg
       Rocktal-research-1-200px.jpg ... Rocktal-research-18-200px.jpg
       Mechas-research-1-200px.jpg ... Mechas-research-18-200px.jpg
       Kaelesh-research-1-200px.jpg ... Kaelesh-research-18-200px.jpg
  2. Tech-ID als PNG oder JPG:
       Humans 11201 ... 11218, Rock'tal 12201 ... 12218, Mechas 13201 ... 13218, Kaelesh 14201 ... 14218

Ein Slot (z. B. MaxTechs11) zeigt die vier Techs mit gleicher Position (Humans-1, Rocktal-1, Mechas-1, Kaelesh-1).
Fehlt eine Datei, bleibt der Platz leer. Die Bilder gehoeren OGame/Gameforge:
nur lokal bzw. im privaten Repo ablegen, nicht ins oeffentliche Repo.
